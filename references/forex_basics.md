# 外汇基础知识参考

## 外汇市场概述

外汇市场（Forex）是全球最大的金融市场，日均交易量超过6万亿美元。外汇交易是指以一种货币兑换另一种货币的行为。

## 货币对报价规则

### 直接报价 vs 间接报价
- **直接报价**：1美元兑换多少本币（如 USD/JPY = 110.50）
- **间接报价**：1本币兑换多少美元（如 GBP/USD = 1.2500）

### 报价解读
- **基础货币**：货币对中左边的货币
- **报价货币**：货币对中右边的货币
- 汇率表示：1基础货币 = X报价货币

例如 EUR/USD = 1.0850 表示：
1欧元 = 1.0850美元

## 影响汇率的主要因素

### 1. 央行政策和利率
- **加息**：货币升值（吸引资金流入）
- **降息**：货币贬值（资金流出）
- 关注央行利率决议和前瞻指引

### 2. 通胀数据
- **CPI（消费者物价指数）**：衡量通胀水平
- **PPI（生产者物价指数）**：上游通胀压力
- 高通胀 → 央行可能加息 → 货币升值

### 3. 经济数据
- GDP增长率：经济健康度指标
- 非农就业：就业市场状况
- 失业率：劳动力市场紧张度
- 制造业PMI：实体经济活跃度

### 4. 地缘政治因素
- 战争、冲突 → 避险情绪 → 瑞郎、日元、美元升值
- 贸易战 → 影响相关货币

### 5. 市场情绪
- 风险偏好：资金流向风险资产（澳元、新兴市场货币）
- 风险规避：资金流向避险资产（瑞郎、日元、美元）

## 技术分析基础

### 趋势判断
- **上升趋势**：低点和高点不断抬高
- **下降趋势**：低点和高点不断降低
- **震荡整理**：高低点无明显方向

### 常用技术指标
- **MA（移动平均线）**：5日、20日、60日、200日
- **RSI（相对强弱指数）**：>70超买，<30超卖
- **MACD**：判断趋势转折
- **布林带**：识别波动区间

### 支撑位与阻力位
- **支撑位**：价格下跌时可能遇到买盘支撑
- **阻力位**：价格上涨时可能遇到卖盘压力

## 风险管理原则

### 仓位管理
- 单笔交易风险不超过总资金的1-2%
- 建议仓位：轻仓（<10%）、中仓（10-30%）、重仓（>30%）

### 止损设置
- 每笔交易必须设置止损
- 止损幅度：日内交易20-50点，隔夜交易50-100点
- 止损设置在关键技术位之外

### 盈亏比
- 建议目标盈亏比：至少1.5:1
- 即盈利潜力至少是亏损风险的1.5倍

## 主要外汇分析方法

### 基本面分析
- 分析经济数据、央行政策、地缘政治等
- 判断货币长期趋势

### 技术面分析
- 分析价格走势、技术指标、形态等
- 寻找入场和出场点位

### 综合分析
- 基本面定方向，技术面定时机
- 多周期共振确认

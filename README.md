# Forex Analysis Skill - 外汇市场分析技能

## 简介

这是一个为 WorkBuddy AI 助手打造的外汇市场分析技能，提供实时行情获取、走势分析和投资建议功能。

## 功能特点

- 📊 **实时行情** - 获取当日外汇市场主要货币对汇率
- 📈 **走势分析** - 分析汇率涨跌原因，结合基本面和技术面
- 💡 **投资建议** - 提供货币对投资方向、风险评级和止损建议

## 支持的货币对

| 货币对 | 货币名称 | 交易特点 |
|--------|----------|----------|
| EUR/USD | 欧元/美元 | 全球交易量最大，流动性最高 |
| GBP/USD | 英镑/美元 | 波动较大，受英国经济影响 |
| USD/JPY | 美元/日元 | 受日本央行政策影响大 |
| USD/CNH | 美元/人民币 | 反映中美贸易关系 |
| AUD/USD | 澳元/美元 | 与大宗商品相关 |
| USD/CHF | 美元/瑞郎 | 避险货币 |

## 安装方法

### 方法一：手动安装

1. 下载或克隆本仓库
2. 将 `forex-analysis` 文件夹复制到 WorkBuddy 技能目录：
   ```
   ~/.workbuddy/skills/forex-analysis/
   ```
3. 重启 WorkBuddy 即可使用

### 方法二：导入 ZIP

1. 下载 releases 中的 `forex-analysis.zip`
2. 解压后放入 `~/.workbuddy/skills/` 目录

## 使用方法

安装后，在 WorkBuddy 中直接询问外汇相关问题即可自动触发：

- "今天美元兑人民币汇率多少？"
- "分析一下欧元走势"
- "哪种货币值得投资？"
- "给我讲讲外汇市场"
